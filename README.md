# VeReady

Repository containing simulation code, optical beam engineering tools, numerical studies and supporting resources developed within the **VeReady** project.

---

## Project overview

VeReady focuses on advanced optical field engineering and structured illumination strategies for fluorescence microscopy and related photonics applications.

---

## Repository structure

### `AziSuperPupilBeam_FluorDeplMicro`

Code and resources associated with the manuscript:

> *Azimuthal super-pupil beam engineering for improved fluorescence depletion microscopy*

[This directory](AziSuperPupilBeam_FluorDeplMicro) contains the scripts used to generate the figures and numerical results presented in the manuscript.

---

### `Characterizations`

Experimental and numerical characterization resources related to beam profiles and optical system performance.

---

### `DOE`

Study of Diffractive Optical Elements (DOE) for the project.

---

### `Reports`

Supporting reports, manuscript versions and related documentation.

---

### `code`

General-purpose code, reusable utilities and auxiliary simulation routines used across the project.
